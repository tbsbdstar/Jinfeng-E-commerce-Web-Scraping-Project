# 抖音（抖店 / 电商罗盘）经营概况数据接口

> 本项目 `platforms/douyin.py` 使用。明文接口，替代了早期"页面文本抓取 + 坐标点日历"的方案。

## 1. 接口地址

```
GET https://compass.jinritemai.com/compass_api/shop/common/homepage/core_index_v3
```

## 2. 请求参数（query string）

| 参数 | 值 | 说明 |
|---|---|---|
| `begin_date` | `YYYY/MM/DD 00:00:00` | 起始日，如 `2026/08/10 00:00:00`。**注意**：斜杠 `/` 分隔、带 `00:00:00`、空格需编码（用 `URLSearchParams` 会自动处理）|
| `end_date` | 同 `begin_date` | 抓单日时与 `begin_date` 相同 |
| `date_type` | `2` | **关键参数**。`2` = 任意历史单日；`20` = 只近 1~2 天（更早报"日期校验失败"）；`1` = 今日实时 |
| `index_selected` | `income_amt,refund_amt,pay_cnt` | 要取的指标，逗号分隔 |
| `activity_id` | 空 | 留空 |
| `operate_type` | `0` | 固定 `0` |

> `verifyFp` / `fp` / `msToken` / `a_bogus` 这些签名参数**可以不传**——在已登录页面里同源 fetch 即可拿到数据。

## 3. 调用方式（关键前提）

必须**在已登录的 `compass.jinritemai.com` 域的页面里**用带 cookie 的 fetch 发起：

```javascript
fetch(url, { credentials: "include", headers: { "accept": "application/json" } })
```

流程：先 `goto https://compass.jinritemai.com/shop` 建立登录会话，再在 `page.evaluate` 里 fetch。
若页面被重定向到 `login`，说明登录态失效，需重新登录。

## 4. 响应结构与取值路径

```
data
 └ module_data
    └ homepage_core_index
       └ compass_general_multi_index_card_value
          └ data[0]                 ← 以「指标名」为 key 的对象
             └ <指标名>
                └ index_value
                   └ value
                      ├ value        ← 数值
                      └ unit         ← 单位类型
```

`st` 字段：`0` = 成功；`100008 / 日期校验失败` = date_type 与日期不匹配（改用 `date_type=2`）。

## 5. 字段映射（本项目取这 3 个）

| 业务含义 | 接口指标名 | unit | 换算 |
|---|---|---|---|
| 成交金额（销售）| `income_amt` | 3 | 值是**分**，÷100 得元 |
| 成交退款金额（退款时间，退款）| `refund_amt` | 3 | 值是**分**，÷100 得元 |
| 成交订单数（订单）| `pay_cnt` | 5 | 原始个数，直接用 |

**单位规则**：`unit=3` → 金额，单位「分」，÷100；`unit=5` → 计数，原始整数。

## 6. 时间段（多天）说明

- 本项目按天存储，取时间段时**逐天循环调用**（每天一次，date_type=2）。
- 若把 `begin_date`≠`end_date` 传成一个区间，接口返回的是**整个区间的汇总值**（不是按天拆分），因此不适合按天入库——按天存储请一天一调。
- 历史可取范围：实测 `date_type=2` 至少可回溯到 15 天前（7/27，今日 8/11）。更早未测。

## 7. 备注

- `business_api/home/home_center_v3` **不是**数据接口，只是页面导航菜单，勿用。
- 其它可选指标（加进 `index_selected`）：`pay_amt`=支付金额、`rfndsuc_amt`=退款成功金额、
  `refund_order_cnt`=退款单数、`refund_amt_rate`=退款率、`per_usr_pay_amt`=客单价、
  `product_show_ucnt`=商品曝光人数、`product_click_ucnt`=点击人数 等。

## 8. 示例返回（截取，8/10 单日）

```json
{
  "st": 0,
  "data": { "module_data": { "homepage_core_index": {
    "compass_general_multi_index_card_value": { "data": [ {
      "income_amt": { "index_value": { "value": { "unit": 3, "value": 123456 } } },
      "refund_amt": { "index_value": { "value": { "unit": 3, "value": 12345 } } },
      "pay_cnt":    { "index_value": { "value": { "unit": 5, "value": 10 } } }
    } ] }
  } } }
}
```
→ 销售 1234.56，退款 123.45，订单 10。
