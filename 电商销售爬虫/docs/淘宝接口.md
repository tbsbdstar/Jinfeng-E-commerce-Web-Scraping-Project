# 淘宝（生意参谋 sycm）店铺核心指标接口

> 本项目 `platforms/taobao.py` 使用。明文接口，替代了早期"自定义日历 data-value 点选 + 页面文本抓取"的方案。

## ⚠ 前提：登录仍须真人 Chrome（与另三家不同）

淘宝登录反爬最强（自动化滑块过不去），**登录态无法脚本化**。必须：
1. 双击 `淘宝Chrome.bat` 开带 `--remote-debugging-port=9222` 的真人 Chrome 并登录淘宝；
2. 脚本用 `connect_over_cdp("http://localhost:9222")` 连接该 Chrome。

接口取数就在这个**已登录的 Chrome 页面上下文**里发起。也就是说：**登录靠人、取数靠接口**。
（另三家小红书/抖音/拼多多可脚本无头登录；淘宝这步省不了。）

## 1. 接口地址

```
GET https://sycm.taobao.com/portal/long/period/nodistinct/coreIndex/getShopMainIndexes/v3.json
```

## 2. 请求参数（query string）

| 参数 | 值 | 说明 |
|---|---|---|
| `dateType` | `compareRange` | **必须**。该接口不认 `dateType=day`（会报"dateType 必传"）|
| `dateRange` | `DATE｜DATE,DATE｜DATE` | 目标区间,对比区间。取**单日**时四个日期填同一天，如 `2026-08-06｜2026-08-06,2026-08-06｜2026-08-06`。URL 编码：`｜`=`%7C`、`,`=`%2C` |
| `needCycleCrc` | `true` | 带环比（用不上也无妨）|
| `device` | `0` | 固定 0 |
| `token` | `<_tb_token_>` | **必须**。从 `document.cookie` 的 `_tb_token_` 读 |
| `_` | 时间戳 | `Date.now()`，防缓存 |

## 3. 调用方式（关键前提）

在**已登录的 `sycm.taobao.com` 页面**（CDP 连来的真人 Chrome）里用带 cookie 的 fetch：

```javascript
const token = document.cookie.match(/_tb_token_=([^;]+)/)[1];
const qs = `needCycleCrc=true&dateType=compareRange`
         + `&dateRange=${ds}%7C${ds}%2C${ds}%7C${ds}&device=0&token=${token}&_=${Date.now()}`;
fetch(base + "?" + qs, { credentials: "include", headers: { "accept": "application/json" } });
```

流程：先确保 page 在 `sycm.taobao.com`（否则 `goto sycm.taobao.com/portal/home.htm`），
再 `page.evaluate` 里 fetch。取不到 `_tb_token_` 或 URL 含 `login` → 登录态失效。

## 4. 响应结构与取值路径

```
content
 ├ code (0=成功) / hasError / message
 └ data                 ← 一个「指标名 -> 值」的大对象（部分指标是 {value:..}, 部分是裸值）
```

## 5. 字段映射（本项目取这 3 个）

| 业务含义 | 接口字段 | 说明 |
|---|---|---|
| 支付金额（销售）| `payAmt` | 元，直接用 |
| 退款金额(完结时间)（退款）| `rfdSucAmt` | 元，成功退款金额，直接用 |
| 支付子订单数（订单）| `subPayOrdSubCnt` | 个 |

> 金额单位是「元」，无需换算。取值时注意：`d[key]` 若是 `{value:..}` 取 `.value`，否则用裸值。
> 订单别用 `payOrdCnt`（支付订单数，非子订单）；本项目口径是「支付子订单数」= `subPayOrdSubCnt`。
> 其它可用：`uv`=访客数、`payByrCnt`=支付买家数、`cartByrCnt`=加购人数、`sucRefundRate`=退款率、`netPaymentAmount`=净付款额 等。

## 6. 时间段（多天）说明

- 本项目按天存储，取时间段时**逐天循环调用**（每天 dateRange 填当天×4）。
- compareRange 的「对比区间」在此填成与目标同一天，环比字段(cycleCrc)会是 0，忽略即可。
- 实测 7/27 ~ 8/6（含跨月）逐天均正常，每次约 0.3 秒（旧日历法约 15 秒/天）。

## 7. 备注

- 接口发现方式：CDP 连真人 Chrome，抓数据概览 XHR，用已知值反查。
- 其它接口：`portal/level/info/v3.json`（层级/成长）、`coreIndex/new/trend/v3.json`（趋势曲线）。

## 8. 示例返回（截取，8/6 单日）

```json
{
  "content": { "code": 0, "data": {
    "payAmt": 1234.56,
    "rfdSucAmt": 123.4,
    "subPayOrdSubCnt": 10,
    "payOrdCnt": 10, "uv": 1000
  } }
}
```
→ 销售 1234.56，退款 123.4，订单 10。
