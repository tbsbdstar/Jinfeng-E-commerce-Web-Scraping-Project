# Jinfeng-E-commerce-Web-Scraping-Project
多平台电商经营数据自动采集与统计分析系统------定时采集前一天的经营数据，汇总成 Excel 报表，推送到企业微信群。

## 功能概览

**采集什么**

| 数据源 | 采集内容 |
|---|---|
| 淘宝 / 抖音 / 拼多多 / 小红书 | 每个平台每天的销售额、退款额、订单数 |
| 聚水潭 ERP | 按产品、按渠道统计的实发数量、实退数量（实退按进仓时间计） |

**产出什么**

- 电商月表：四个平台按天汇总，每月一份
- 聚水潭周表：渠道 × 日期 × 产品，底部依次为实发数量、实退数量、净发货（总计 = 实发 − 实退）
- 每日群消息：前一天的数据和 Excel 附件，聚水潭文字分实发 / 实退 / 净发货三行
- 周报：每周一先把上周整周重采核对一遍，再出周报

**怎么运行**

- 两个 Windows 定时任务：每天 10:00 采电商、10:15 采聚水潭（错开时间，避免抢浏览器）
- 采集复用一个常开、已登录 5 个平台的 Chrome 窗口（通过 CDP 连接），平时不用反复登录
- 主数据每采完一天就落盘，所有报表都从主数据生成，重复采集不会把数据弄乱
- 提供可视化控制台：手动采集与补采、登录状态检测、每日数据总览与缺口提示、产品分类维护、定时任务管理、日志与报错汇总

## 目录结构

四个目录必须保持平级，控制台按"同级目录"自动定位另外三个工程。

```
├── 采集控制台/          可视化主程序（启动.bat），以及打包脚本和部署模板
├── 常开页面爬取工具/      常开浏览器登录与两个定时任务的入口脚本
├── 电商销售爬虫/         淘宝 / 抖音 / 拼多多 / 小红书 采集、月表与周报
└── 聚水潭爬虫/          聚水潭实发 / 实退采集、周表渲染、分类编码模板
```

各工程的详细说明见：`采集控制台/使用说明.md`、`常开页面爬取工具/使用说明.md`、
`电商销售爬虫/docs/`、`聚水潭爬虫/docs/`。

## 环境要求

- Windows 10 及以上
- Python 3.12（3.11 / 3.13 一般也能运行）
- Google Chrome
- 依赖：`playwright`、`openpyxl`、`requests`、`winsdk`（安装脚本会自动安装）

## 部署

任选一种：

1. **生成部署包**：在仓库根目录执行 `python 采集控制台/打包部署包.py`，在仓库的上一级目录得到部署包 zip，
   解压后双击 `安装.bat`。
2. **直接安装**：把 `采集控制台/部署模板/` 里的 `安装.bat` 和 `install.ps1` 复制到仓库根目录，双击 `安装.bat`。

安装脚本会安装依赖、注册两个每日定时任务、在桌面创建快捷方式，并自检三个采集工程的位置。
完整步骤见 `采集控制台/部署模板/部署说明.md`。

## 首次使用需要自己配置

仓库中的配置已做脱敏处理，部署后请补上：

| 配置项 | 位置 | 说明 |
|---|---|---|
| 企业微信群机器人地址 | `电商销售爬虫/config.json`、`聚水潭爬虫/config.json` 的 `wecom` | 填 `webhook`，并把 `enabled` 改为 `true` |
| 平台账号（可选） | 复制 `电商销售爬虫/credentials.example.json` 为 `credentials.json` 后填写 | 仅小红书 / 抖音 / 拼多多支持自动填表登录 |
| 店铺名后缀 | `聚水潭爬虫/config.json` 的 `channel_shop_suffix` | 用于匹配聚水潭报表里的渠道名，例如「抖音-店铺名」 |
| 聚水潭产品与商品编码 | 控制台「产品分类」页，或直接编辑模板 Excel 的「分类编码」sheet | 决定采哪些商品、周表有哪些产品列 |
| 数据存储目录（可选） | 各工程 `config.json` 的 `output_dir` | 默认是工程内的 `outputs/`，可填绝对路径 |

最后在控制台「浏览器 / 登录」页打开常开浏览器，逐个登录 5 个平台。淘宝有滑块、聚水潭报表站不代填，
这两个只能人工登录。

## 仓库不包含的内容

- 登录档案（`browser_profiles/`）、账号密码（`credentials.json`）
- 业务数据（`outputs/` 下的主数据与报表）、运行日志
- 开发期的探路脚本与修改前备份

文档中出现的销售金额、订单数等均为示意值，不是真实经营数据。

> 填好 webhook 和账号后，请不要把 `config.json`、`credentials.json` 提交回公开仓库。
> 本地可执行 `git update-index --skip-worktree 电商销售爬虫/config.json 聚水潭爬虫/config.json`，
> 让 git 忽略这两个文件的本地改动。

## 注意事项

- **不要在运行这套系统的电脑上手动调系统时钟**。时钟被往前调过后，定时任务的"上次运行时间"会被记成未来值，
  之后每天都会被判为"已运行"而跳过；遇到这种情况需要删除并重建两个定时任务，具体方法见
  `采集控制台/部署模板/CLAUDE.md` 第五节。
- 聚水潭某产品当周退货多于发货时，净发货显示为负数，这是正常的净值口径。
