# 多平台电商经营数据自动采集与统计分析系统 V1.0 · 使用说明

给现有采集工具套的一层可视化界面。**不改动现有工具的任何文件**——点按钮时它是以子进程去调用
`常开抓取.py` / `常开抓取-聚水潭.py` / 各项目 `core/runner.py` 里的函数，等同于你手动双击那些 bat。
所以它坏了不影响采集，采集照样能用原来的 bat 跑。

## 怎么打开

双击 **`启动.bat`**（无黑窗）。
界面起不来时改双击 `诊断启动.bat`，出错信息会留在窗口里。

## 七个页签

### 启动
顶部一条状态：常开浏览器**在线/未运行**（绿/红）、下次定时时间、两边数据各自到哪一天了
（有一边还没到昨天会标红提醒）。下面一屏做完三件事：

1. **选平台** —— 淘宝 / 抖音 / 拼多多 / 小红书 任意勾选，聚水潭（实发/实退）单独一项。
   勾了电商又勾了聚水潭，会先跑完电商再跑聚水潭，不会互相抢浏览器。
2. **选时间范围** —— 填 `2026-08-26` 这种格式，或直接点快捷按钮：昨天 / 前天 / 最近3天 /
   最近7天 / 本周 / 上周 / 本月 / 上月。右侧实时显示"共 N 天"。
   数据有一天延时，所以默认是昨天；选到今天或未来会弹窗提醒。
3. **选运行方式** ——
   - *常开浏览器*（默认）：复用常开 Chrome 里已登录的标签页，快、不用重登。
   - *独立无头*：自己开后台浏览器，常开那个挂了/连不上时用。
   - *推送企业微信群*：**默认不勾**。手动补抓一般不该推群（免刷屏、免和定时推的重复）。
   - *抓前重启常开浏览器*：CDP 卡死、连不上时勾上，会杀掉常开 Chrome 再全新拉起（登录态在
     profile 里，不会丢）。

点「开始采集」，下方黑框实时滚动进度，成功绿色、失败红色、警告黄色。中途可以「停止」，
**已经抓到的数据不会丢**（主数据是抓一天存一天）。

输出框下面四个按钮分别打开：**电商销售数据**目录、**聚水潭实发/实退数据**目录、
**本月月表**、**本周周表**——两套数据存在各自项目的 `outputs` 里，所以是两个目录。

### 浏览器 / 登录
**登录失效时就来这一页处理。**

**常开浏览器状态**：在线/未运行 + 端口 + 当前几个标签页。两个按钮——
「刷新状态」重新探测；「打开 / 重启浏览器」在没开时把它拉起来并开好 5 个平台标签，
已经开着时会问你是"全新重启"（CDP 卡死、页面无响应时选它，登录态在 profile 里不会丢）
还是"只补齐标签页"。

**各平台登录状态表**：点「检测全部」会真去验一遍（不是猜）——常开模式下是逐个平台调用采集程序
自己的登录判定；独立无头模式下是打开各项目的登录档案验。5 个平台约 40 秒。
状态分三种：**已登录**（绿）、**已失效**（红，确实跳到了登录页，需要人工重登）、
**页面未就绪**（橙，当前不在登录页，多半是加载慢或网络问题，**不用重登**，稍后重测即可）。
双击某行可单独重测那个平台。

表里另有两列：**账号**（打码显示，只让你确认配的是哪个号；密码从不读取、从不显示）、
**自动登录**（支持 / 缺密码 / 需人工）。

### 配置账号密码（就在工具里改）
点「配置账号密码」，弹出配置窗口，四个电商平台的账号密码可直接在里面改：

- **账号**预填当前值，随时可改；
- **密码留空 ＝ 不改动原有密码**，只有你真的填了才会覆盖。所以改账号时不必重新输密码，
  也不会因为没填而把密码清空；
- 密码框默认密文显示，可勾「显示我输入的密码」核对有没有打错；
- 保存前会列出"要改哪些平台的账号、要更新哪些平台的密码"让你确认；
- 保存写入的是**现有工具原本那份** `电商销售爬虫\credentials.json`
  （保留 `_说明` 等原有内容、保留键顺序、保持原有编码），
  所以现有的 `登录.bat`、`配置账号.bat` 照样能读、能用，两边改都行。

> 改成另一个账号后，该平台原有的登录态属于**旧账号**，必须重新登录一次才生效——
> 窗口里有「保存后立即打开电商登录工具」可以顺手做掉，状态表里那个平台也会自动标成"待重登"。
> 另外换号后抓到的是新店铺的数据，会与历史数据存进同一份主数据，注意口径。

几个要点：

- 账号密码**只在"建立登录态"那一步用一次**。登录工具据此自动填表，验证码/短信由你在弹出的
  窗口过一遍，登录成功后登录态存进各项目的 `browser_profiles\`；**之后每天抓取只用登录态，
  不再用密码**。所以密码填了不等于能一直免登录，登录态照样会过期。
- 能自动填的只有 **小红书、抖音、拼多多** 三家。**淘宝有滑块、聚水潭报表站不代填**，
  这两个任何模式下都只能真人登录。
- `credentials.json` 是**明文保存在本机**的（现有工具的既有设计），不随工具分发。
  这台机器给别人用或移交时记得处理。

> 检测走哪种方式，跟着「启动」页选的**运行方式**走——因为两种模式的登录态是**两份独立的东西**：
> 常开模式用常开 Chrome 里的会话，独立模式用各项目 `browser_profiles/` 下的档案。
> 换句话说，常开里登录了不等于无头模式也能用，反之亦然。

**登录失效了怎么办**，这一页底部按两种模式分别给了入口：

| 运行方式 | 怎么处理 |
|---|---|
| 常开浏览器 | 点「打开登录窗口（5 个平台标签）」→ 在弹出的 Chrome 里把标红的平台重登一遍 → **窗口别关** → 回来点「检测全部」确认变绿 |
| 独立无头 | 三步：① 点「① 配置账号密码」在工具里填好账号密码 → ② 点「② 电商登录工具」（自动填账号密码开有头浏览器，验证码/短信你过一遍）或「聚水潭登录工具」 → ③ 回来点「检测全部」确认变绿。淘宝走「淘宝（真人 Chrome 过滑块）」 |

登录好之后，回「数据」页看哪几天缺，双击那一行日期就填进启动页，补抓即可。

> 采集过程中如果检出登录失效，跑完会**自动弹窗**告诉你是哪个平台失效了，并可一键跳到这一页。
> 淘宝有滑块，**任何模式下都只能真人登录**，脚本过不去。

### 数据
最近 7/14/30/60 天的每日总览，一张表看完两套数据：

| 列 | 含义 |
|---|---|
| 淘宝 / 抖音 / 拼多多 / 小红书 | 当天各平台销售额 |
| 电商合计 | 四平台销售额之和 |
| 实发 / 实退 | 聚水潭当天全产品全渠道合计 |
| 净发货 | 实发 − 实退 |

**红色行 = 那天有平台没数据**（今天不算，数据要次日才出）；勾「只看有缺口的日期」可以只留下
要补的天。**双击任意一行，日期会自动填进「启动」页**，勾好平台点开始就补上了。

底部还能一键打开：电商数据目录、聚水潭数据目录、本月月表、本周周表、最新周报 txt。

右上角**「校验上周（约 7 分钟）」**：把上周（周一~周日）的聚水潭实发/实退整周重采一遍，
用最新值覆盖主数据并重渲周表，**不推群**。这是给日常抓取兜底的——实测日常单次抓取仍会
偶发漏记（8/17~8/30 两周事后复核补回 17 套实退）。周一的定时任务已经自动做这件事，
这个按钮供你想校验时随时手动触发。注意它会覆盖你手工改过的周表。

### 产品分类
维护聚水潭的**分类编码**——采集抓哪些商品编码、周表有哪些产品列、日报周报列哪些产品，
全部由这张表决定。以前只能手改模板 Excel，现在可以在这里改。

表格三列：产品名称 / 订货分类 / 商品编码，每个产品的第一行有浅色底纹便于分组。按钮：

- **新增产品**：填产品名称＋订货分类＋商品编码（订货分类留空＝与产品名称相同）
- **给选中产品加编码**：一个产品多条编码时用，会自动插到该产品那几行的后面
- **修改选中 / 删除选中**：双击某行也能直接改
- **上移 / 下移**：顺序就是周表里产品列的先后
- **保存到模板**：保存前会列出「编码条数变化、新增了哪些产品、移除了哪些产品」让你确认
- **打开模板 Excel**：想直接在 Excel 里改也可以，两边等价

> 改完**下次采集起生效**，不用改任何代码。
> **同一个商品编码不能归到两个产品下**（会重复计数），保存时会拦下来。
> **删掉某产品只是以后不再采集，主数据里的历史记录不会被删除**。
> 新增产品后想补历史数据，去「启动」页把那段日期重跑一遍即可。

### 定时
列出所有跟采集相关的 Windows 计划任务，显示状态、下次运行、上次运行、上次结果、执行命令。
选中一行后可以：改每日运行时间、启用、禁用、立即运行一次。

> 「立即运行一次」等同于定时到点，**会真的抓取并推送企业微信群**，点之前会二次确认。
> 现有两个任务是 `电商爬虫_常开模式`（10:00）和 `聚水潭爬虫_常开模式`（10:15），
> 错开是为了避免同时开浏览器争抢资源，改时间时请保持错开。

### 日志
翻阅三个来源的运行日志：控制台自己的、电商采集的、聚水潭采集的。
选日期、填关键字过滤、勾「自动刷新」可以边跑边看。ERROR 红色、WARNING 橙色。

### 报错
把最近 3/7/14/30 天里所有日志的 **ERROR、WARNING** 汇总到一张表，外加各项目 `outputs` 目录下的
**登录失效标记文件**，按时间倒序，可按来源筛选、可只看错误。双击看完整内容。

这一页是**只读**的，不会删任何东西。看到"登录已过期/登录态失效"时的处理：
在常开 Chrome 里重新登录该平台 → 回到「启动」页把那一天补抓一遍即可。

## 文件说明

| 文件 | 作用 |
|---|---|
| `启动.bat` | 双击启动（正常使用） |
| `诊断启动.bat` | 带黑窗启动，界面起不来时排错用 |
| `console.py` | 界面主程序 |
| `worker.py` | 执行器，被界面以子进程调用；也可单独命令行用（见文件头注释） |
| `settings.json` | 自动生成，记住你上次选的平台/模式/推送选项 |
| `logs/` | 控制台自己的操作日志（与采集工具的日志分开存） |

## 注意

- **别和定时任务同时跑并且都推送**，群里会收到两份。界面在检测到定时任务正在运行时会提醒。
- 采集期间**别打开正在写的 Excel**（月表/周表），被占用时现有工具会另存一个"请关闭原文件后替换"的副本。
- 本工具只依赖 Python 自带的 tkinter，换台电脑不用额外装东西（采集本身需要的
  playwright / openpyxl 仍由原项目负责）。
- 现有工具的位置由 `paths.py` 解析：先找**同级目录**，再读 `paths.json`，最后回退历史默认值。
  整体搬家一般不用改任何东西；位置特殊时改 `paths.json` 即可。
