# 交接清单（一页纸）

**多平台电商经营数据自动采集与统计分析系统 V1.1**　部署包 20260911　交接日 9 月 12 日
采集范围：淘宝 / 抖音 / 拼多多 / 小红书 + 聚水潭　·　每天 10:00 电商、10:15 聚水潭　·　推送群不变

---

## 一、接手方（新机器，约 40 分钟，多数时间在登录）

**1. 先装两样东西** —— Python 3.12（务必勾 *Add Python to PATH*）、Google Chrome。

**2. 解压部署包** —— 例如 `D:\数据采集系统\`。路径可含中文和空格，**不要有 `&` `%` `^`**。
解压后四个目录**必须平级**：采集控制台、常开页面爬取工具、电商销售爬虫、聚水潭爬虫。

**3. 双击根目录 `安装.bat`** —— 装依赖、注册定时任务、建桌面快捷方式（需联网）：

- `电商爬虫_常开模式` 每天 10:00
- `聚水潭爬虫_常开模式` 每天 10:15
- 两个都设了"错过时间自动补跑"

**4. 登录 5 个平台（唯一必须人工做的一步）** —— 桌面快捷方式 → 「浏览器 / 登录」页 →
『打开登录窗口（5 个平台标签）』→ 逐个登录 淘宝、抖音、拼多多、小红书、聚水潭。

> **登录完不要关那个 Chrome 窗口**，它就是"常开浏览器"，每天采集靠复用它的登录状态。
> 回控制台点『检测全部』，五项全绿才算好。

**5. 试跑一次** —— 控制台点「采昨天」，确认：群里收到消息、消息是**实发 / 实退 / 净发货**三行、
Excel 附件能打开。⚠ 这一步会真往群里发，先在群里说一句"测试"。

**6. 往后不用管** —— 每天自动采前一天、出表、推群；每周一自动复核上周再出周报。
**需要电脑开机、常开 Chrome 不关。**
（可选：要用"独立无头"方式才需填小红书/抖音/拼多多账号密码；淘宝有滑块、聚水潭报表站不代填，只能真人登录。）

## 二、移交方（旧机器，两件事，都在新机跑通当天做）

**1. 停掉本机两个定时任务** —— 两台都开着的话，同一个群会收到两份推送、数据重复采：

```
schtasks /change /tn "电商爬虫_常开模式" /disable
schtasks /change /tn "聚水潭爬虫_常开模式" /disable
```

先**禁用**别直接删，观察一周新机器没问题再清。（也可在"任务计划程序"里右键禁用。）

**2. 把账号和最后几天数据补给接手方** —— 部署包不含账号密码和登录档案，5 个平台账号需另外给。
包里历史数据截止 **9 月 10 日**（最后一天已采）；9/11 起本机若又自动跑过，把这两个文件拷过去覆盖同名文件即可
（月表 / 周表 / 周报都能由它们重新生成）：

- `电商销售爬虫\outputs\daily_master.csv`
- `聚水潭爬虫\outputs\jst_master.csv`

或者让接手方在控制台「数据」页看缺口，把缺的那一两天手工补采一次，结果一样。

## 三、常见状况

| 现象 | 怎么办 |
|---|---|
| 双击快捷方式没反应 | 改双击 `采集控制台\诊断启动.bat`，错误信息留在黑窗口里 |
| 提示"找不到采集工程" | 四个目录没保持平级；调整目录或改 `采集控制台\paths.json` |
| 某平台"已失效" | 掉登录了，在「浏览器 / 登录」页重登该平台 |
| 某平台"页面未就绪" | 不是掉登录，是加载慢；稍后点『检测全部』重测 |
| 定时任务当天没跑 | 电脑关机了；开机后自动补跑，缺多天用「数据」页手工补采 |
| 聚水潭某产品净发货是负数 | 正常。净发货 = 实发 − 实退，当周退货多于发货就是负的 |

更详细的见：根目录 `部署说明.md`、`打包清单.txt`，以及 `采集控制台\使用说明.md`。
