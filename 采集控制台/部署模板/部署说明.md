# 多平台电商经营数据自动采集与统计分析系统 V1.1 · 部署说明

本包含整套系统的四个工程、安装脚本与文档。**不含**登录状态与账号密码，
所以到新机器上需要重新登录一次、重填一次账号密码。

**这一包到底带了什么，以根目录的 `打包清单.txt` 为准**（是否附带历史数据、构建时间都写在那里）。

## 一、装到哪里

解压到任意目录即可，例如 `D:\数据采集系统\`。解压后应该是这样四个平级目录：

```
数据采集系统\
├── 安装.bat              ← 双击这个开始
├── install.ps1
├── 部署说明.md            ← 本文件
├── 采集控制台\            ← 可视化界面（主程序）
├── 常开页面爬取工具\        ← 登录态复用与定时入口
├── 电商销售爬虫\           ← 淘宝/抖音/拼多多/小红书采集
└── 聚水潭爬虫\            ← ERP 实发/实退采集
```

> **四个目录必须保持平级。** 控制台靠"同级目录"自动找另外三个工程，位置对了就不用配路径。
> 万一你把它们分散放了，编辑 `采集控制台\paths.json` 填写实际路径即可。

**路径里不要带特殊符号**（`&`、`%`、`^` 等），中文和空格没问题。

## 二、安装

双击 **`安装.bat`**，它会依次做五件事：

1. 查找 Python 3.12（找不到会提示你先去装，记得勾 *Add Python to PATH*）
2. 安装依赖：`playwright`、`openpyxl`、`requests`、`winsdk`；
   检测系统 Chrome，没有则下载 Playwright 内置浏览器
3. 注册两个每日定时任务：`电商爬虫_常开模式`（10:00）、`聚水潭爬虫_常开模式`（10:15），
   并设置"错过时间自动补跑"。**已存在的同名任务会保留原设置，不会被覆盖**
4. 在桌面创建快捷方式
5. 自检三个采集工程的定位结果

需要联网（装依赖）。中途某个包装失败不影响其它步骤，脚本会提示你手动补装。

## 三、安装后必须做的两件事

部署包出于安全不含登录信息，以下两步只需做一次。

### 1. 各平台登录（必做）

打开系统 → 「浏览器 / 登录」页 → 点 **打开登录窗口（5 个平台标签）** →
在弹出的 Chrome 里逐个标签登录：淘宝、抖音、拼多多、小红书、聚水潭。

**登录完不要关那个 Chrome 窗口**，它就是"常开浏览器"，每天的采集靠复用它的登录状态。
登录完回到系统点 **检测全部**，五项都变绿即可。

### 2. 配置账号密码（可选）

只有要用"独立无头"方式时才需要。点 **配置账号密码**，填小红书、抖音、拼多多的账号密码
（这三家支持自动填表登录）。**淘宝有滑块、聚水潭报表站不代填，任何方式下都只能真人登录。**

## 四、日常使用

- 每天 10:00 / 10:15 定时任务自动采集前一天数据，出报表并推送企业微信群，无需人工干预
- 要补数据、看缺口、查日志、改定时，双击桌面快捷方式打开系统操作
- 每周一定时任务会把上周整周重新校验一遍再出周报（约 7 分钟）

详细操作见 `采集控制台\使用说明.md`。

## 五、这个包里没有什么

| 没打包的东西 | 为什么 | 影响 |
|---|---|---|
| `browser_profiles\` 登录档案 | 体积大（近 2GB），且属于登录凭据 | 需按第三节重新登录一次 |
| `credentials.json` 账号密码 | **明文保存的账号密码，不随包分发** | 需在控制台里重填 |
| `outputs\` 历史报表 | 体积大，且都能由主数据重新生成 | 见下方"历史数据" |
| `logs\` 运行日志 | 与新机器无关 | 无 |
| `_dev\`、测试脚本、缓存 | 非正式模块 | 无 |

**历史数据**：整套系统的"唯一真相源"就是下面两个 CSV，月表 / 周表 / 周报都能由它们重新生成：

- `电商销售爬虫\outputs\daily_master.csv`
- `聚水潭爬虫\outputs\jst_master.csv`

打包时加 `--带数据` 的包**已经带上这两个文件**（看 `打包清单.txt` 是否列出）；
没带的话，从旧机器把这两个文件拷到新机器对应位置即可。放好后在控制台「数据」页点刷新，
历史就回来了；要重出某周/某月的报表，在「报表」页重新生成一次即可。

## 六、企业微信推送

推送地址（群机器人 Webhook）在 `电商销售爬虫\config.json` 和 `聚水潭爬虫\config.json` 里，
**已随包带上**，装完就能往原来那个群推。要换群就改这两个文件里的 `wecom.webhook`；
不想推送把 `wecom.enabled` 改成 `false`。

> 注意：Webhook 相当于往群里发消息的钥匙，别把这个包发给公司以外的人。

## 七、从旧机器换到新机器（接手时按这个顺序做）

两台电脑都开着定时任务的话，**同一个群会收到两份推送**，数据也会被重复采两遍。所以：

1. **新机器**：按第二、三节装好、登录好，先在控制台点一次「采昨天」跑通，确认群里能收到消息、
   Excel 生成正常（这一步会推一条到群里，事先跟群里说一声是测试）。
2. **旧机器**：确认新机器跑通的当天，把两个定时任务停掉——
   任务计划程序里找到 `电商爬虫_常开模式`、`聚水潭爬虫_常开模式`，右键"禁用"；
   或者管理员命令行执行：

   ```
   schtasks /change /tn "电商爬虫_常开模式" /disable
   schtasks /change /tn "聚水潭爬虫_常开模式" /disable
   ```

   先"禁用"不要直接删，观察一周新机器没问题了再删除。
3. **交接当天的数据别落空**：切换那天谁先跑谁采，另一台不用补。
   如果切换当天两台都没跑，在新机器控制台「数据」页看缺口、手工补采那一天即可。
4. 旧机器上的 `browser_profiles\`（登录档案）不用迁，也不建议迁——新机器重新登录更干净。

## 八、遇到问题

| 现象 | 处理 |
|---|---|
| 双击没反应 / 界面起不来 | 改双击 `采集控制台\诊断启动.bat`，错误信息会留在黑窗口里 |
| 提示"找不到采集工程" | 四个目录没保持平级，按第一节调整，或改 `采集控制台\paths.json` |
| 提示"常开浏览器未运行" | 「浏览器 / 登录」页点『打开 / 重启浏览器』 |
| 某平台"已失效" | 按第三节第 1 步重新登录该平台 |
| 某平台"页面未就绪" | 不是掉登录，是加载慢或网络问题，稍后点『检测全部』重测 |
| 定时任务没跑 | 电脑当时关机了。开机后会自动补跑一次；缺多天用「数据」页看缺口手工补采 |

## 九、V1.1 相对 V1.0 改了什么

- **聚水潭周表底部三行**：改成 `实发数量` / `实退数量` / `净发货（总计）`（净发货 = 实发 − 实退）。
  某产品当周实退大于实发时会显示负数，这是正常的净值口径。
- **每日推群文案**：由两行改为三行——实发 / 实退 / 净发货，各带合计。
- **三个 sheet 自适应列宽**（实发数量 / 实退数量 / 分类编码）。
- **各个 .bat 不再写死 Python 路径**：按 `%LOCALAPPDATA%` → `%ProgramFiles%` → `C:\Python312` → PATH
  的顺序自动找，找不到会明确提示装 Python，换电脑不用改脚本。`淘宝Chrome.bat` 同理会自动找 Chrome。
